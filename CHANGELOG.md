# maturity-skills

## 0.2.0

### Minor Changes

- [`f1232e6`](https://github.com/ANcpLua/maturity-skills/commit/f1232e6fca905fdbbe54ea036fa2ab4b76d2b241) - Add agent-log-scan: a model-invoked skill plus a deterministic, stdlib-only streaming scanner (`agentlog.py`) that mines Claude Code transcript corpora for antipatterns — retry-loops, permission-thrash, API dead-ends, usage-limit interruptions, silence-gaps, cross-session error clusters, and per-tool error rates — without ever loading raw logs into context. Findings carry file:line and byte offsets for O(1) drill-down via `slice` and `bisect`, message text is withheld by default (`--show-text` opts in), and `scan` exits 2 when detectors fire so CI can gate on transcript health. The routine classifies each antipattern as an infrastructure, agent-native, or user-flow fault and ends with concrete allowlist, routine, and harness-config changes.

- [`2392b13`](https://github.com/ANcpLua/maturity-skills/commit/2392b132f915f3b0ada99eea4ff2ff1116a79c3f) Thanks [@ANcpLua](https://github.com/ANcpLua)! - Add regression-review and maintenance-run, distilled from four autonomous maintenance runs on dotcov. regression-review adversarially reviews only the previous change-set's diff for bugs that change-set itself introduced: diff range derived from the last run/PR/merge, prime-suspect ordering (new invariants, semantic-duplicate helpers, gate disjuncts, exception filters, boundary comparisons), current-code reading around every hunk, concrete failure scenarios required, and a pinning test with every fix — the pass that scored a real self-introduced bug in 3/3 consecutive runs. maintenance-run packages the proven orchestration loop: parallel finders reusing the sibling skills as dimensions, a dedupe arbiter clustering raw findings by root cause before verification, refute-by-default adversarial verifiers whose fix_adjustment overrides the finder's proposal, a fixer fleet with disjoint file ownership in isolated worktrees (two-wave sequencing on API dependencies, per-fixer green gate, rejection-is-terminal conduct rules), single-writer integration, a run report with the findings-curve datapoint, regression-review as the next run's opener, and a hard termination rule: when a run's findings are predominantly regressions of the previous run's own changes, the target is done.

- [`90307bf`](https://github.com/ANcpLua/maturity-skills/commit/90307bfdf735061f479bd59a8e19669044333f54) Thanks [@ANcpLua](https://github.com/ANcpLua)! - maintenance-run: add `scripts/findings.py`, a deterministic, stdlib-only findings-dedupe tool that mechanizes the mechanical share of the dedupe-arbiter step. `dedupe` clusters raw findings by transitive closure over two join rules — root-cause signature token-set overlap >= 1/2 after agentlog-style normalization (paths/ids/hex/numbers stripped), and identical normalized titles — picks each cluster's primary by severity then evidence, merges dimensions, reports every merge edge with its reason, and emits an explicit `ambiguous` list for the LLM arbiter: same-file pairs within a ±15-line window (`--window`) flagged with their line distance, plus similar-but-below-threshold signature pairs. Line proximity deliberately never merges — replayed against maintenance run-002's arbiter ground truth (34 raw findings -> 26 clusters), 4 of 7 same-file near-line pairs were distinct claims and no window setting separates them, while every true near-line pair is captured on the ambiguous list with zero false merges. `validate` schema-checks finder output with actionable per-field errors; `dedupe` warns on stderr when findings omit `root_cause`, which the handoff now requires (title-only output reaches none of the cross-file merges). Exit codes: 0 nothing merged, 2 merges happened, 1 usage/schema errors; same input yields byte-identical output (exact-fraction similarity, no hash-order dependence). SKILL.md step 2 now runs the tool first and treats tool merges as a floor, not a ceiling: the arbiter judges the ambiguous list, may split a tool cluster with a stated reason, and may merge unflagged pairs with stated code evidence — never re-clustering from scratch.

- [`a2636f4`](https://github.com/ANcpLua/maturity-skills/commit/a2636f4071a3d1841da87002eabc7516ecf2a3af) Thanks [@ANcpLua](https://github.com/ANcpLua)! - agent-log-scan: new `ledger` subcommand — a workflow efficiency ledger over subagent workflow runs (`wf_*/journal.jsonl` + `agent-<id>.jsonl`). Per run and per agent it reports started/completed counts, tool calls (deduped by tool_use id), output tokens and input+cache tokens (final usage snapshot per API message, streaming duplicates deduped by message id), context tokens (the agent's final context footprint, reproducing the workflow runner's own per-agent token counter), wall/per-agent durations, and agent labels from the runner state file or meta.json — deterministic, streaming, byte-identical on rerun, and privacy-default (labels and numbers only, never prompt or message text). `--outcomes <json>` joins run results (confirmed/fixed/tests_added/mutants_killed/note) and emits tokens-per-finding so fleet-size decisions are priced from measured runs. Ships a fixture-based self-test (`test_ledger.py`) with hand-computed numbers, and SKILL/docs sections on the ledger routine: run it before each new maintenance target and compare tokens-per-finding across runs.
